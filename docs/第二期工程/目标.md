# 需求

我先在这里写一下最终的需求，但是中间过程可能还得在你的协助下，慢慢收集资料，和你慢慢探究。

现在这个项目可以做到每次跑出今年到现在的deepmodeling社区贡献者名单对吧。
最终需求：
我希望最终它可以每天由其他软件或者智能体触发跑一次，更新总量的同时，记录增量？
于此同时，希望它能够每天更新到飞书群里，这里可能需要探索一下实现方式？我设想的有两个：
1、用脚本（or让飞书的智能体）维护一个飞书多为表格，能够根据表格内容生成图标也很方便在飞书中查看。
2、维护一个网页，去展示今年，本月，本周，昨天，的pr、commit等字段以及贡献者的统计，以及展示图表，再由飞书的智能体每天定时把链接发到飞书群里。
3、或者就是有数据就行，每天由飞书智能体把统计信息发到群里。


如何实现，或者能够通过什么方式去实现，或者先初步实现再慢慢探索更好的实现方式，需要你来协助探索。
需要什么资料你可以先websearch找不到的可以搭配我人工检索，比如飞书的各种api文档，可能你不一定能看到，我们一步一步来收集然后探索。
