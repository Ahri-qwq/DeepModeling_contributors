# 临时任务「获取内容」摸底结论

> 日期：2026-08-17
> 对应需求：`docs/临时任务/获取内容.md`
> 一句话结论：任务要的是「软件使用量/流行度」指标，与现有贡献者统计工具基本不重叠，需新写采集脚本；指标绝大多数是公开数据、无后台权限门槛，当前主要缺口是「软件↔各平台包名」的映射表尚未逐项核实。

## 一、任务要什么

从 9 个软件身上取三类内容，最终产出一份**静态报告**：

1. GitHub/Gitee 仓库页：star、fork、watch 数，release 发布记录及下载量。
2. PyPI / npm / Docker Hub / conda 等平台的下载量统计（带时间序列）。
3. 国内镜像站（阿里云、清华镜像）收录页面。

## 二、软件归属（关键发现）

「这些软件都在 DeepModeling 下面」这个前提不成立。GitHub 上有两套组织账号：

- `deepmodeling` —— 开源社区组织（几十个仓库）。
- `dptech-corp` —— 深势科技公司自己的组织（放偏公司侧/前沿项目）。

实际定位如下（`deepmodeling`、`dptech-corp` 两个组织的仓库清单已用 `gh api` 实查确认）：

| 文档条目 | 实际定位 | 备注 |
|---|---|---|
| DeepModeling | `deepmodeling` 组织本身 | 是组织账号，不是单个仓库 |
| DeePMD-kit | `deepmodeling/deepmd-kit` | 含 DPA-1/2/4 模型系列 |
| DP-GEN | `deepmodeling/dpgen` | |
| Uni-Dock | `dptech-corp/Uni-Dock`（另有 Uni-Dock2） | 在公司组织，不在社区 |
| DMFF | `deepmodeling/DMFF` | |
| Uni-Mol | `deepmodeling/Uni-Mol` | |
| DPA | 并入 DeePMD-kit，不单列 | 见下 |
| Uni-Fold | `deepmodeling/Uni-Fold` 与 `dptech-corp/Uni-Fold` 均有 | 一个软件两个仓库 |
| Uni-RNA | 未定位到官方仓库 | 待确认 |

### 关于 DPA

DPA 不是独立软件，而是 DeePMD-kit 内部的一套「模型描述符」系列（DPA-1 / DPA-2 / DPA-4），
全部活在 `deepmodeling/deepmd-kit` 一个仓库里，无独立仓库、无独立 PyPI 包。

- DPA-1：早期描述符，多后端支持。
- DPA-2：大原子模型，DeePMD-kit v3 官方发布的主推亮点。
- DPA-4（SeZM）：v3.2.0b0 新加入。

处理建议：并入 DeePMD-kit，不单独出数字（没有独立数字可出）。若需体现 DPA-2 大模型热度，
在 DeePMD-kit 行备注里注明「含 DPA-1/2/4 模型系列」即可。

### 待确认项

- Uni-RNA：两个组织均未找到官方仓库（搜到 `sjtugrc/Uni-RNA`，描述对得上但 star 为 0，不像官方主推）。需再查 Gitee，或确认是否未开源 / 名称对不上。

## 三、现有项目能做到什么程度

本项目（`github_contributors`）是「贡献者统计」工具，采集的是 commit / PR / Issue / Review / Comment，
**与任务所需指标基本不重叠**：

| 任务所需 | 现有项目 | 差距 |
|---|---|---|
| star / fork / watch 数 | 只取 `is_fork` 做分类，不统计数量 | 差一个 API 调用 |
| release 记录及下载量 | 无 | 新写 |
| PyPI / npm / Docker / conda 下载量 | 无，只连 GitHub | 新写 |
| 国内镜像收录 | 无 | 新写 |

**能复用的只有基础设施**：GitHub token 鉴权、仓库清单获取。GitHub 侧指标（star/fork/release）
加几个 REST 调用即可拿到；包平台下载量与镜像收录需从零新做。

## 四、各指标可获取性

| 指标 | 获取方式 | 是否需权限 |
|---|---|---|
| GitHub star/fork/watch | REST `/repos/{owner}/{repo}` | 公开；匿名 60 次/h，用 token 5000 次/h（本项目已有 token） |
| GitHub release 及下载量 | REST `/releases` | 公开 |
| PyPI 下载量（含时间序列） | `pypistats.org` 免费 API，可按天/月 | 公开免费 |
| conda 下载量 | anaconda.org / conda-forge API | 公开 |
| Docker Hub 下载量 | 网页公开；API 拿精确 pulls 通常需免费 Docker Hub 账号 | 基本公开，可选登录 |
| npm | 公开 API | 不适用（这些是 Python/C++ 项目） |
| 国内镜像收录 | 看镜像站网页确认有无收录 | 公开 |

结论：**能获取，且无需后台/企业权限**。唯一实质门槛不是权限，而是「软件↔包名」映射表填错会导致数字全错。

## 五、交付形式

静态报告（一次跑、产出一份「软件 × 指标」表格/文档），非每日刷新看板。

## 六、还差什么 / 下一步
